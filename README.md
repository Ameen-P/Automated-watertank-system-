# Automated-watertank-system-
Smart Automatic Water Tank Management and IoT Monitoring System powered by the NXP LPC2129 ARM7 microcontroller. Features dual-sensor water level validation (Analog + Ultrasonic), automated pump &amp; servo valve control, ThingSpeak cloud telemetry via ESP-01, dual data logging (EEPROM &amp; SD Card), RTC event timestamping, and CAN bus multi-node support.
